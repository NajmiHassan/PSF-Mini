About this project

The problem

Protein sequencing techniques like mass spectrometry sometimes produce incomplete protein sequences with missing positions, called scaffolds. Filling these gaps accurately is important for protein function prediction and drug design.

The original paper

This project is inspired by "PSF: A Web Application Tool for Protein Scaffold Filling", which presents a Django-based web platform combining machine learning and deep learning models for scaffold filling. The original is hosted at psf.ncat.edu.

What this mini version does

Mini-PSF reproduces the core idea with a much simpler, explainable model: a k-mer frequency table. We scan through a reference set of real proteins and record, for every position, which amino acid sits between a given pair of left and right neighbors. To fill a gap, we look at the surrounding amino acids and predict the middle position from the frequency table. 

for each position i in the protein:
    left  = sequence[i-2 : i]
    right = sequence[i+1 : i+3]
    table[(left, right)][sequence[i]] += 1

This is the same family of techniques (n-gram / k-mer language modelling) that underlies more sophisticated deep learning models — just stripped to its essence so the algorithm is fully visible.

Tech stack

  • Backend: Django 4 (Python)
  • Algorithm: Pure-Python k-mer frequency model
  • Database: SQLite (stores prediction history)
  • Frontend: Vanilla HTML + CSS

Limitations

Honest disclosure: the reference dataset is intentionally small, so confidence will drop on contexts the model hasn’t seen. The algorithm falls back to global amino-acid frequencies in that case — the per-gap table marks this as fallback. Production tools like the original PSF use deep neural networks trained on hundreds of thousands of proteins.
